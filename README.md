Entry for make.fun's **"One Word From Your Ex"** bounty ($2, winner-take-all).
The task: send exactly one word your ex would use to describe you — the
funniest, most painfully honest word takes the whole reward.

This entry's word is **Draft** — as in "draft boyfriend": the rough version
she revised into someone else. See [BENCHMARK.md](BENCHMARK.md) for the
pairwise comparison against other candidate words and the words already in
the field.

## Run it

```sh
python3 main.py
```

It writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) — exactly 5 bytes, no trailing newline,
deterministic and byte-identical across runs.
